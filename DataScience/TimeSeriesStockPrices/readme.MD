## 📊 Techniques Used
- Exploratory Data Analysis (EDA) with Pandas/Matplotlib/Seaborn  
- Time Series Decomposition (Trend, Seasonality, Residuals)  
- ARIMA/SARIMA modeling for forecasting  
- LSTM/GRU deep learning models for sequence prediction  
- Rolling averages, moving windows, volatility analysis
